# 🐱 PixelCat – Desktop Pet

A tiny pixel cat that lives on your desktop! ✨

PixelCat is a cute animated desktop companion built with Python. It brings a little personality to your screen with cat animations and adorable sound effects.

## 🌸 Features

- 🐾 Animated pixel cat companion
- 😾 Different cat expressions and moods
- 🔊 Cute sound effects
- 🎵 Meowing and purring sounds
- 🖥️ Desktop-based pet experience

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/pixelpetalcodes/PixelCat.git
```

### 2. Navigate to the project folder

```bash
cd PixelCat
```

### 3. Run the project

```bash
python pet.py
```

Make sure Python and any required project dependencies are installed before running.
